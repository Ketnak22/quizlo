# Seed map sources

`continents.svg` and `voivodeships.svg` were generated with [mapshaper](https://github.com/mbloch/mapshaper)
from [Natural Earth](https://www.naturalearthdata.com/) data, which is in the public domain:

- `ne_110m_admin_0_countries`: countries dissolved into continents. Russia is split at the Urals and
  French Guiana is moved to South America, because the source files them under Europe.
- `ne_10m_admin_1_states_provinces`: the 16 Polish voivodeships.

The boundaries are simplified for a quiz and are not suitable for reference use.
