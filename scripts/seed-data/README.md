# Seed map sources

`continents.svg` was generated with [mapshaper](https://github.com/mbloch/mapshaper) from the
`ne_110m_admin_0_countries` [Natural Earth](https://www.naturalearthdata.com/) data, which is in the
public domain. Countries are dissolved into continents. Russia is split at the Urals and French
Guiana is moved to South America, because the source files them under Europe.

The sample maps in `public/demo-maps` come from the same source. The voivodeships use
`ne_10m_admin_1_states_provinces`.

The boundaries are simplified for a quiz and are not suitable for reference use.
